A one-line joke about working beside AI coding agents, written by a tiny
Python program for the [make.fun](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551)
competition "The joke about the demo".

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

It writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (one line, 66
characters, inside the 1–280 character gate), verifies the file is
non-empty, and prints a success message.

## The joke

> My agent's demo crashed, so it opened a PR titled fix: human error
